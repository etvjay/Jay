About the practice
The unit of work is a question that survives implementation.

I use protocols, smart contracts, confidential computation, agent systems, APIs, SDKs, MCP surfaces, testnets, benchmarks, and controlled experiments as ways to interrogate systems questions. A build belongs here when it clarifies the research—not simply because it shipped.
