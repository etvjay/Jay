Concord

A coordination and execution system for multi-party capital relationships that keeps private formation separate from public economic truth.

I built Concord around an FXRP-backed syndicated capital facility to test whether multiple independent providers can coordinate private terms inside one persistent relationship without collapsing provider-level authority, exposure or settlement lineage.

01 / Problem

Capital can be composed without requiring every provider to become one balance.

The question was whether one facility could coordinate several independent capital providers while preserving whose authority, exposure and settlement lineage produced each part of the facility.

Traditional pooling can intentionally homogenize capital. Concord tests a different requirement: retain a parent relationship for the facility while keeping provider-specific child relationships visible and independently accountable.

02 / Product model

The Root Accord coordinates; Child Accords preserve local economic identity.

Root Accord
   │
   └── Makkari FCC session
         │
         └── CoFill allocation
               │
               ├── Child Accord A ─ funded capacity ─ draw leg A
               ├── Child Accord B ─ funded capacity ─ draw leg B
               └── Child Accord C ─ funded capacity ─ draw leg C

Repayment
   └── restores capacity to the corresponding child relationships

The relationship graph remains durable across confidential formation, public funding, draws, repayment and restored capacity.

Root Accord

Canonical facility-level relationship and parent for the composed capital structure.

Makkari

Bounded FCC session for coordinating confidential provider terms.

CoFill

Deterministic lowest-fee-first allocator with a partial final allocation.

Child Accord

One provider's governed commitment, funding state, exposure and lineage inside the root.

Draw / DrawLeg

Execution decomposed across funded child relationships rather than erasing provider provenance.

03 / What I built

The implementation spans onchain relationships, confidential coordination and evaluator-facing evidence.

The current system includes Solidity relationship/facility contracts, a Go FCC extension, deterministic CoFill allocation, Coston2 deployment and evidence records, typed SDK/API/MCP surfaces, and a frontend with both deterministic replay and fresh wallet-bound sandbox flows.

AccordRegistry

Relationship identity plus explicit parent-child lineage.

CapitalFacility

FXRP collateral, selected versus funded capacity, draws, exposure, repayment, expiry and close rules.

FCC extension

Encrypted quote handling, signature validation and deterministic allocation logic.

Shared surfaces

REST/OpenAPI, TypeScript SDK and MCP preparing unsigned intents without taking custody or verifier authority.

04 / Technical decisions

Selection, funding and exercisable capacity are different states.

An allocation does not become liquidity merely because a confidential coordinator selected it.

Concord only treats provider capacity as funded after the provider transfer succeeds. That distinction is then carried into child-level exposure and multi-child draw construction.

Private formation, public consequence

The confidential session is intentionally bounded to formation. Accepted capacity, provider funding, draws, repayment and parent-child lineage remain public on Coston2. The design does not claim private EVM execution or private token transfers.

06 / Boundary

What Concord does not claim.

Concord does not claim hardware-backed production confidentiality, private FXRP or USDT0 transfers, private EVM execution, or that a development EOA is a native FCC proof verifier.

The current confidentiality boundary is a development path around a public economic relationship. Accepted executable capacity, exposure, funding, draws, repayment and relationship lineage remain onchain.

07 / Research produced

Concord extends the programmable-relationship question into composition.

OpenRails pressured the relationship as a durable coordination object. Concord asks whether those relationships can themselves compose while preserving local authority and failure boundaries.
