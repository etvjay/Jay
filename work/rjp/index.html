RJP

Reasoned Judgment Protocol: reproducible evidence into bounded, revisioned judgments downstream systems can use.

Research questionPositionExperimentBuildEvidenceBoundaryLineage

Research question

How can a system move from raw onchain behavior to actionable trust without reducing complex evidence to an opaque reputation score?

Position

Evidence, case construction, assessment, judgment, and consumption should remain explicit artifacts. A judgment should be domain-scoped, revisioned, inspectable, and independent from the policy a downstream consumer applies to it.

Experiment

Observe Base activity, build reproducible evidence and case objects, materialize bounded judgments on GenLayer, mirror compact state back to Base, and compare judgment-aware agents with direct non-judgment-aware baselines.

Build

Observation → evidence → case → judgment → mirrored state → independent action.

RJP includes an evidence builder, DomainSpec/CaseObject/AssessmentArtifact/JudgmentObject protocol objects, GenLayer intelligent contract, Base mirror and consumers, benchmark harnesses, API adapter, and frontend.

Evidence

  • Reproducible Base evidence builds and offline case verification.
  • Live GenLayer evidence submission and judgment materialization.
  • Mirrored Base judgment reads and handshake previews.
  • Judgment-aware versus direct agent benchmarks.
  • SAFE → ALLOW, UNSAFE → DENY, and INSUFFICIENT_DATA → REFRESH paths demonstrated by domain and evidence state.

Current boundary

RJP is not a global reputation score. Judgments are bounded by domain, subject, evidence, observation window, freshness, and revision history; downstream systems retain their own decision policy.

Research lineage

observation → reproducible evidence → bounded judgment → independent downstream action
