RJP

A bounded judgment layer that turns reproducible onchain evidence into revisioned judgments downstream systems can actually use.

Research questionPositionExperimentBuildEvidenceBoundaryLineageSource

Research question

How can a system move from raw onchain behavior to actionable trust without reducing complex evidence to an opaque reputation score?

Working position

Evidence, case construction, assessment, judgment, and consumption should be explicit artifacts with domain scope, revision history, and downstream policy left to the consumer.

Experiment

Observe Base activity, build reproducible evidence and case objects, materialize bounded judgments on GenLayer, mirror compact state back to Base, and benchmark judgment-aware versus judgment-free downstream agents.

Build

RJP includes an evidence builder, durable protocol objects, GenLayer intelligent contract, Base mirror and consumers, agent benchmarks, API adapter, and web frontend.

Evidence

  • Reproducible Base evidence builds and offline case verification.
  • Live GenLayer evidence submission and judgment materialization.
  • Mirrored Base judgment reads and handshake previews.
  • Judgment-aware versus direct agent benchmarks.
  • Multiple bounded judgment outcomes demonstrated by domain and evidence state.

Current boundary

RJP is not a global reputation score. Judgments are domain-scoped, evidence-bounded, revisioned, and designed for independent downstream consumption.

Research lineage

Observation → reproducible evidence → bounded judgment → independent action.
