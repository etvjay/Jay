Coordination Without Shared State

Do actors need the same internal knowledge in order to produce compatible outcomes?

01 / Testable hypothesis

Coordination may require compatible action boundaries rather than shared internal state.

If the hypothesis is correct, parties should be able to retain different private inputs, policies and constraints while revealing only enough information to support a safe joint consequence.

02 / Experimental apparatus
NOX ACCORD ↗

Private offer submission, confidential comparison, bounded allocation and selective disclosure.

Concord ↗

Private provider formation combined with public Root/Child Accord capacity, exposure and settlement lineage.

independent variables:
  amount of shared information
  compatibility rule
  allocation rule
  visibility boundary

observables:
  whether coordination completes
  whether authority remains bounded
  whether public consequence is interpretable
  whether private inputs remain undisclosed
03 / Run ledger

The key variable is how much must become mutually visible.

RUN-001
Full shared state baseline
Use a conceptual baseline where all relevant offers and constraints are mutually visible. This is the maximum-disclosure control against which selective-disclosure runs are compared.
PLANNED
RUN-002
Private offers → shared allocation
NOX ACCORD tests whether offer terms can remain private while the allocation result required for the next step becomes visible.

RUN-003
Private policies → compatibility output
Keep policy interiors distinct and expose only compatibility or selected outcome rather than the full rule set.
PLANNED
RUN-004
Insufficient disclosure
Deliberately withhold one field required for safe execution and observe whether the next actor can detect that coordination is under-specified rather than proceeding blindly.
PLANNED
RUN-005
Sufficient selective disclosure
Reveal only the bounded result and authority context needed for the next action; test whether coordination succeeds without exposing private formation inputs.
IMPLEMENTED
RUN-006
Private formation → public economic consequence
Concord records private formation separately from public Child Accord funding, draw legs, repayment and restored capacity.
OBSERVED
04 / Current result

Selective disclosure is a viable coordination boundary in the tested systems.

The recurring pattern is not “everyone knows the same thing.” It is “each actor receives enough information to act safely at the next boundary.”

05 / What it does not establish

This does not establish that all coordination can avoid shared state, or that privacy is always beneficial. Some workflows may require full disclosure, shared ledgers or synchronized state because the action itself depends on common knowledge.
