Persistent Agency

When does prior execution become memory that actually changes later autonomous behaviour?

HypothesisApparatusControlEvidenceCurrent resultFalsification
01 / Hypothesis

Execution history becomes operational memory only when it causally changes a later action.

02 / System under test
Engram ↗

Records execution episodes, admits operational lessons, recalls comparable experience and traces explicit influence.

03 / Experimental control
control run:
  comparable context
  no relevant memory
  → action A

memory run:
  comparable context
  relevant admitted memory
  → action B

question:
  did the memory explain the action delta?
04 / Evidence

Engram currently tests changed-action scenarios, stale-memory rejection, competing memories and wrong-recall provenance. The strongest evidence is deterministic and conformance testing; live cloud integrations remain separately classified.

05 / Current result

Retrieval and influence are observably different states.

A memory can be retrieved and still be blocked. A memory can be exposed and still fail to influence the decision. The experiment therefore treats “memory” as a causal claim rather than a storage claim.

06 / What would falsify it

If later action differences cannot be reliably distinguished from ordinary nondeterminism or contextual drift, Engram cannot claim causal execution memory.
