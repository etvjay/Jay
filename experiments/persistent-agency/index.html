Persistent Agency

When does prior execution become memory that actually changes later autonomous behaviour?

7 defined runsdeterministic controlsprogramme active
HypothesisApparatusControlRunsResultNext run
01 / Testable hypothesis

Execution history becomes operational memory only when it causally changes a later action.

If the same action would have happened without the recalled memory, then retrieval occurred but memory influence was not demonstrated.

02 / Experimental apparatus
Engram ↗

Records execution episodes, admits operational lessons, retrieves comparable memories and preserves influence provenance.

03 / Control condition
control execution:
  comparable context
  no relevant memory
  → decision A

memory execution:
  comparable context
  relevant admitted memory
  → decision B

required observation:
  A != B
  AND decision B explicitly references the memory
  AND provenance links the memory to its source execution

05 / Current result

Retrieval, exposure and influence are distinct observable states.

The experiment supports a stricter definition of memory: prior execution must produce a reconstructable action delta, not merely appear in context.

What the experiment currently establishes

Under deterministic scenarios, Engram can distinguish retrieved-but-blocked memory from memory that is explicitly referenced by a later decision and changes the selected action relative to a control.

06 / What it does not establish

The external workloads are simulated. These runs do not establish that every real-world agent decision is causally attributable to memory, or that live CockroachDB/Bedrock/AWS integration claims have been externally verified.

07 / Next smallest run
